## 🚀 How to Run in VS Code

1. In **VS Code**, go to File > Open Folder... and select D:\thm-fluid-technik.
2. To view the site:
   - **Option A (Instant)**: Right-click index.html > select **Open with Live Server** (if you have the Live Server extension).
   - **Option B (Direct)**: Simply double-click index.html to open it in any web browser (Chrome, Edge, Firefox).

## ✨ Features Included

- **Pixel-Matched Design**: Exactly reflects the reference layout, branding colors (Red #E31B23 + Dark Navy #061327), typography, and card shapes.
- **Hero Stats Animated Counter**: 20+ Years, 1000+ Clients, 5000+ Products delivered.

  - *Get a Quote / Contact Us* form modal popup.

- **Call to Action Capsule**: High-converting contact banner.
